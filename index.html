Crie um jogo em etapas

MobileForge é um framework 2D guiado por código. Você controla o estado e desenha cada quadro, como no MonoGame. O editor reúne arquivos, sprites e prévia no mesmo lugar.

ProjetoCicloDesenhoEntradaSpritesExportação

1. Projeto e arquivos

Crie arquivos .js em Arquivos JS. Eles executam na ordem da lista. Deixe setup, update e draw em main.js, que fica por último. Classes e funções dos arquivos anteriores podem ser usadas nele.

O projeto é salvo no navegador. Faça um backup .json para conservar código e sprites em outro aparelho.

2. Ciclo do jogo

function setup(game) {
  // Uma vez ao iniciar.
}
function update(game, dt) {
  // A cada quadro; dt é o tempo em segundos.
}
function draw(game) {
  game.clear('#101827');
  // Desenhe o quadro inteiro.
}

A tela lógica mede 360 × 640 pixels e se adapta ao tamanho físico mantendo a proporção.

3. Desenho

game.clear('#101827');
game.rect(20, 30, 80, 40, '#5ce0b4');
game.circle(180, 120, 24, '#ffcc66');
game.text('Pontos: 10', 16, 36, 20, '#fff');

O desenho é imediato: você decide a aparência de cada quadro.

4. Toque e teclado

if (game.pointer.down) {
  player.x = game.pointer.x;
  player.y = game.pointer.y;
}
if (game.key('ArrowRight')) player.x += 180 * dt;

game.pointer contém x, y e down.

5. Sprites

Crie um sprite, desenhe seus pixels ou importe um PNG. Esta versão aceita sprites de até 64 × 64 pixels e preserva a transparência.

game.sprite('hero', player.x, player.y, 3);

O último número é a escala. O nome deve ser igual ao exibido no explorador.

6. Teste e exporte

Jogar reinicia a prévia. Erros aparecem no console. Exportar HTML baixa um único arquivo com o motor, o código e os sprites; basta abri-lo em um navegador.

Com teclado físico: Ctrl + Enter para jogar e Ctrl + S para salvar.
