ARTE DO JOGO

Sprites

Crie um sprite ou importe um PNG de até 256 × 256 pixels.

Use Graphics.Sprite("nome", x, y, escala) em Draw(). As alterações aparecem ao executar novamente.

CONSTRUA SEU MUNDO

Tilemaps

Crie um spritesheet para pintar mapas.

Em Draw(), use Graphics.Tilemap("nome", x, y, escala). Cada célula guarda um índice do spritesheet.

Toque na tela do exemplo para mover. O código roda no seu dispositivo.

Compilação

Os erros aparecerão aqui, com arquivo e linha.
COMECE PELO MAIN

Você controla o jogo.

O projeto começa em MainGame : Game. Essa classe cria seus objetos e decide quando atualizar e desenhar cada um.

1. O ciclo

Start() executa uma vez. Update(float dt) atualiza a lógica: dt é o tempo em segundos desde o quadro anterior. Draw() desenha na tela.

2. Classes e arquivos

Crie Player.cs para definir a classe. Em MainGame, declare public Player Player = new Player();. Depois chame Player.Update(dt) e Player.Draw() nos métodos correspondentes.

Os arquivos compilam juntos como um projeto C#. A ordem das abas não importa. Use using MobileForge; para acessar a engine.

3. Desenho e entrada

Graphics.Clear("#101827");
Graphics.Rect(10, 20, 48, 48, "#80e6b9");
Graphics.Sprite("hero", 10, 20, 3);
Graphics.Text("Olá!", 16, 40);

if (Input.Down) X = Input.X;
if (Input.Key("ArrowRight")) X += 180 * dt;

A tela lógica tem 360 × 640 pixels. Input.X, Input.Y e Input.Down representam o toque. Na aba Sprites, desenhe ou importe PNG, divida em células e crie mapas. Use Graphics.Tile("sheet", índice, x, y, escala) ou Graphics.Tilemap("mapa", x, y, escala).

4. Testar e corrigir

Toque em Executar. O compilador Roslyn verifica todos os arquivos. Toque em um erro para ir à linha. A barra acima do teclado ajuda a inserir símbolos; as sugestões incluem palavras de C# e a API da engine.

5. Levar o jogo

Após compilar, baixe o ZIP. Extraia todos os arquivos juntos na mesma pasta e abra index.html. Todos ficam na raiz do ZIP. Backup salva o projeto editável em JSON. O Chrome pode restringir arquivos vizinhos quando abre por um provedor content://; nesse caso hospede o conteúdo extraído como site estático.

Limites desta prova

Esta é uma API própria, inspirada no MonoGame. Ainda não há física, áudio, NuGet ou autocomplete semântico. As bibliotecas disponíveis são as incluídas no runtime; não é um ambiente .NET desktop completo.
